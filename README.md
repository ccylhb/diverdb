# DiverDB - Dave the Diver Guide Site (Astro)

Static guide and database site for Dave the Diver, built with Astro and hosted for free on
Cloudflare Pages.

Live: <https://ccylhb.github.io/diverdb/>
Cloudflare mirror: <https://diverdb.pages.dev>

Popular pages:
- [Fish Database](https://diverdb.pages.dev/fish/)
- [Recipe Database](https://diverdb.pages.dev/recipes/)
- [Tools](https://diverdb.pages.dev/tools/)

## Quick start

```bash
npm install          # install dependencies
npm run dev          # local dev server (http://localhost:4321)
npm run build        # build static site into dist/
npm run preview      # preview the production build
```

> If npm install fails with broken native deps (shiki / @rollup), delete
> `node_modules` and `package-lock.json`, then reinstall. Use a mirror registry
> if you are in China: `npm install --registry https://registry.npmmirror.com`.

## Project structure

```text
src/
  layouts/Base.astro       # global layout: nav, footer, SEO meta, dark theme
  data/fish.json           # 232 fish and creatures (scraped from Fandom wiki)
  data/recipes.json        # 306 recipes
  data/staff.json          # 24 restaurant staff members
  data/weapons.json        # 29 weapons
  data/bosses.json         # 16 bosses
  pages/
    index.astro            # homepage: tools, databases, fresh guides
    fish/ recipes/ staff/ weapons/ bosses/  # searchable database pages
    tools/                 # fish farm planner, recipe filter, staff compare
    guides/                # beginner, farming, economy, staff, weapons, bosses
```

## How data is maintained

The JSON files in `src/data/` are generated by `work/research/scrape_diverdb.py`
from the public Dave the Diver Fandom API. Re-run the scraper after a game update,
then spot-check key values against the live game before rebuilding.

## Deployment

Cloudflare Pages:
- Build command: `npm run build`
- Output directory: `dist`
- GitHub Actions workflow is included in `.github/workflows/deploy.yml`.

Before launch, replace `https://diverdb.pages.dev` with the real domain in
`astro.config.mjs` and `public/robots.txt`.
